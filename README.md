# SpendWise Dashboard

## Project Title

**SpendWise Dashboard Shell – CSS Grid & Flexbox**

## Project Overview

SpendWise Dashboard is a modern, responsive financial dashboard shell designed as the foundation for a future personal finance and expense-tracking capstone project.

The purpose of this project is to create the visual structure of a financial management dashboard using **HTML5 and modern CSS techniques**. The dashboard does not include JavaScript functionality or database integration because the focus of this week's assignment is on layout, styling, responsiveness, and user-interface design.

The dashboard provides users with a clear overview of their financial information, including their total balance, monthly spending, savings, and spending across different categories.

The project demonstrates the use of **CSS Grid, Flexbox, CSS custom properties, responsive design, hover effects, keyboard focus states, and a dark theme**.
